# Рябов за творчество

Сайт для оценки музыки: релизы, регистрация, оценки по критериям в реальном времени.

## Стек

- Next.js (App Router) + TypeScript
- Prisma + SQLite
- JWT-сессии в cookie

## Запуск

```bash
npm install
npm run db:setup
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Формула оценки

1. **База** = сумма 4 критериев (1–10 каждый) → 4–40  
2. **Множитель вайба** = `1 + (вайб − 1) × 0.075` (от 1.000 до 1.675)  
3. **Итог** = база × множитель

## Сейчас в MVP

- Главная со списком релизов, хедер и футер
- Вход / регистрация
- Страница релиза: средний балл, форма оценки с ползунками, список оценок
- Импорт дискографии «Ежемесячные» из Deezer + MusicBrainz

### Импорт «Ежемесячные»

```bash
# Deezer + MusicBrainz
npm run import:ezhe

# Полная дискография + даты с Genius (~69 релизов)
npm run import:genius
```

`GENIUS_ACCESS_TOKEN` в `.env` — для официального API. Если токен невалиден, скрипт автоматически использует публичный `genius.com/api`.

Админ-панель, баны, метки, премии и автоподтягивание релизов — на следующих этапах.
